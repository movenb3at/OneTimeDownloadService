03

실행하기

압축을 푼 폴더에서 start.cmd를 더블 클릭하세요. 처음에는 프로젝트 전용 Python 가상환경, 패키지와 공식 cloudflared를 준비합니다. 실행 창은 열어 두세요.

start.cmd

전역 패키지나 Windows 서비스·방화벽 설정은 변경하지 않습니다.

04

관리자 설정

최초 실행의 콘솔에서 12자 이상의 관리자 비밀번호를 입력하고 확인하세요. 입력은 화면에 표시되지 않습니다. 콘솔에 표시된 공개 관리자 주소를 열어 로그인하세요.

비밀번호는 scrypt 해시로 저장합니다. 관리자 주소를 파일 공유 링크 대신 전달하지 마세요.

05

첫 번째 파일 공유

관리자에서 최대 90MiB 파일을 업로드하고 공유 링크를 복사하세요. 상대방은 공유 화면에서 다운로드 화면으로 이동해 파일을 받습니다. 전체 수신과 SHA-256 검증 후 파일 저장을 제공합니다.

주소 끝의 #token= 부분까지 전달하세요. 완료는 브라우저의 수신·검증 기준이며 실제 디스크 저장을 확인하지 않습니다.

06

관리와 종료

같은 브라우저에서 최초 시작부터 10분간 재시도할 수 있습니다. 관리자는 새 링크 발급, 기록 초기화와 파일 삭제를 할 수 있습니다. 실행 창에서 Ctrl+C를 누르면 서버와 터널이 종료됩니다.

재실행 후 터널 주소가 바뀌면 링크를 다시 복사하세요. 쿠키나 주소가 달라져 재시도할 수 없다면 새 링크가 필요합니다. 파일은 자동 삭제되지 않습니다.

로컬 실행, 비밀번호 재설정, 데이터 백업과 자세한 정책은 저장소 사용 설명서에서 확인하세요.
